# TrisoNet Trading Zone

A fully clickable, role-aware prototype of the TrisoNet Trading Zone — Africa's premier marketplace.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Mock/local data (no backend)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Roles

Switch roles using the Role Switcher in the top-right header:

- 👑 **Super Admin** — final product approval
- 🔍 **QC Officer** — quality control review
- 📦 **Business Manager** — submit products to Market Square
- 🏪 **Citizen Seller** — manage personal portal listings
- 🛒 **Buyer** — browse and purchase
- 👀 **Visitor** — browse only (checkout gated)

## Prototype Tour

Click the **Prototype Tour** button (bottom-right) for a guided 9-step walkthrough of the full product flow.
